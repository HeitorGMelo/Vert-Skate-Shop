🛹 Vert Skate Shop

Um projeto de portfólio inspirado em uma loja de skate moderna, com foco em UX, organização visual e decisões conscientes de design.
Este projeto foi desenvolvido com HTML, CSS e JavaScript puro, priorizando fundamentos sólidos antes de frameworks como React.

📌 Sobre o Projeto
O objetivo principal é demonstrar:
-Estruturação de interface moderna
-Organização de catálogo por categorias
-Decisões reais de UX (não só estética)
-Código simples, escalável e bem pensado

🧠 Decisões UX
“Ofertas da Semana” como contraste visual proposital"
A seção Ofertas do Dia é única no layout:
-Visualmente mais agressiva (vermelho/urgência)
-Serve como ponto fixo de atenção
-Permanece estável mesmo quando o usuário troca de categoria

✅Decisão consciente: simplicidade antes de complexidade
Apesar de animações automáticas (ex: troca infinita de imagens) serem uma UX possível, foi decidido não implementar agora, para manter:
-Entrega rápida
-Clareza no código
-foco em fundamentos

🛠️ Tecnologias Utilizadas
-HTML5
-CSS3
-JavaScript(Vanilla)
